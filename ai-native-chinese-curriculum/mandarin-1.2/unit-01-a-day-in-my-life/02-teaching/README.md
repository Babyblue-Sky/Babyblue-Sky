# 02 Teaching — 说明

一个 Unit 通常包含 **5–6 个 Cycle（对应 5–6 份 Teaching Slides）**，具体数量根据该 Unit
的教学需求而定，不是固定值。本 Unit 1 实际教了 7 个 Cycle（`cycle-1.md` ~ `cycle-7.md`），
2026-08-04 已全部整理进 Content Layer。

**每个 Cycle 的格式（2026-08-04 教师反馈后定案）**：每节课只保留三项——
**Do-Now**（开场问答/热身）、**Objective**（"我会..."学习目标）、**Main Activities**
（当天主要课堂活动）。不再逐条记录语法点、课堂常规模板说明、Cycle 级生词汇总、备注——
教师原话"太长了，学生们不会看的，太多信息等于无效信息"。历史决策和踩过的坑仍然记在
`08-curriculum-intelligence.md`，不是丢失了，只是不重复放进这个面向学生/家长的文件。

每个 Cycle 一个文件：`cycle-1.md` ~ `cycle-7.md`。
